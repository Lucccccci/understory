# v0.1 · 从私人版本到开源版本做了什么

> 这份文件是给**以后的自己**看的：升级、回滚、或者重新做一次开源时，
> 知道哪些东西是"为了开源"动过的，不要误以为是功能。
>
> 私人版本是带着具体角色的；开源版抹掉了角色，只留机制。

---

## 一、新增的东西（私人版没有的）

| 新增 | 位置 | 为什么 |
|---|---|---|
| **启动向导** | `web/setup.html` + `/api/setup` | 没有角色就不能硬编码名字；第一次启动让使用者自己填 |
| **人设模板** | `personas/blank.json` | 空模板 + 一段"照着填"的人格正文骨架 |
| **示例人设** | `personas/example.json` | 虚构角色「阿岚」，只演示字段怎么填 |
| **城市配置** | `settings.json → city` | 原来写死在一个城市；现在由使用者填经纬度 |
| **占位立绘** | `assets/face/face_default.png` | 没有立绘也不至于显示破图 |
| **QQ 配置进向导** | 向导里的 QQ 一栏 | QQ 号、SnowLuma 目录、面板密码都能在界面里填 |
| **bridge 配置生成** | `build_bridge_config()` | 原来要手写 `bridge_config.json`；现在按 settings 自动生成 |
| **一键接 QQ** | 左栏按钮 + `_start_bridge()` | 注入成功后自动把 bridge 拉起来 |
| **窗口启动器** | `desktop.py` | 网页 + 系统窗口；pywebview → Edge 应用模式 → 浏览器 三层降级 |
| **LICENSE** | `LICENSE` | MIT |
| **维护规则** | `AGENTS.md` | 中性版：只讲规矩，不讲来历 |
| **本文件** | `docs/v0.1-open-source.md` | 变更摘要 |

---

## 二、删掉的东西

| 删除 | 原因 |
|---|---|
| **角色语料** `tools/corpus/` | 那是"她"的台词库，属于角色不属于框架 |
| **语音** `mind_speech.py` / `run_gsv_train.py` / `web/voice.js` | v0.1 不做语音；`/api/tts` 与 `/voice.js` 路由已停用 |
| **角色立绘与训练数据** `assets/` 下的大部分 | 属于角色 |
| **历史快照与一次性脚本** | 与框架无关 |
| **旧启动脚本** `start_qq.bat`（NapCat 时代） | 路径已失效 |

## 三、改名的东西（全部不影响调用）

```
模块        shu_*.py                 → mind_*.py（32 个）
            game_save.py             → world_save.py
            game_weather.py          → world_weather.py
            mind_gamelines.py        → mind_lines.py
目录        shu-framework            → mind-framework
存档 role   "shu"                    → "her"（旧档读入时自动迁移）
存档文件    saves/shu.json           → saves/legacy.json
请求头      X-Shu-Session            → X-Mind-Session
环境变量    SHU_*                    → MIND_*
备份包      shu-*.zip                → mind-*.zip
CSS/JS      .msg.shu / shuPaintRail  → .msg.her / mindPaintRail
```

**兼容性**：旧存档里的 `role: "shu"` 会在读档时映射成 `"her"`；
`X-Shu-Session` 头不再被识别（v0.1 起统一用 `X-Mind-Session`）。

## 四、修掉的问题（都是"抹人格"过程中暴露的）

| 问题 | 原因 | 修法 |
|---|---|---|
| 空人设启动即 500 | `personas/stage_examples.json` 不存在 | 缺文件返回空 |
| 「让她开口」500 | 人设缺 `slowBurnRules` / `emotionGuide` 等键 | `load_persona` 补默认值 |
| 首启 diagnostics 一串红字 | 就绪探测不带会话头 → 被当无头请求 | 探测带 `X-Mind-Session` |
| 两个实例抢同一端口 | Windows 上 `SO_REUSEADDR` 允许绑已占用端口 | 先 `connect` 再 `bind` |
| 窗口一片空白 | Edge profile 放在带"低完整性"标签的目录 | profile 移到 `%TEMP%` |
| 点「做到了」没反应 | 多条承诺的 `at` 相同 + 匹配顺序按日期 | 匹配改原话优先，日期唯一化 |

## 五、故意保留的（不要"顺手改掉"）

```
role 值 "her"              —— 存档协议；再改必须同时写迁移
世界存档键 "Shu"/"Luccci"  —— 读别人存档格式用的，改成自己的就读不出来
世界标签 "the valley"      —— 外部数据里的专名，不是我们的命名
```

## 六、版本约定

```
v0.1   机制齐全的试用版：心境/记忆/日记/星图/向导/QQ 一键
       接口与 persona 字段仍可能变
       升级前请备份 saves/

后续   私人版（带角色的）在本仓库基础上继续开发 ——
       角色只改 personas/，不要动 core
```
